# 🌐 Public APIs Directory

> A free, community-maintained collection of public APIs across every domain — science, finance, government, entertainment, health, and more. Built for developers, students, and hackathon teams who need to find a working API fast.

⭐ **If this saved you time, star the repo — it helps other developers find it too.**

## Why this exists

Most "public API" lists are either outdated, unorganized, or missing key info (does it need auth? does it support HTTPS? is it free?). This repo aims to fix that with:

- ✅ **Auth** column so you know instantly if you need an API key
- ✅ **HTTPS** column so you know it's secure
- ✅ **CORS** column so front-end devs know if they can call it directly from the browser
- ✅ Organized by **department/domain**, not dumped in one giant list
- ✅ Open to contributions — see [CONTRIBUTING.md](CONTRIBUTING.md)

**Legend:** `Auth` = None / API Key / OAuth | `HTTPS` = Yes/No | `CORS` = Yes/No/Unknown
